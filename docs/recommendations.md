# 首页推荐与可选 AI

搜索页默认显示「猜你喜欢」，所有推荐采用同一种封面网格，不再区分精选、接着听等分组。
播放全部替换当前播放队列，歌单和喜欢不受影响；单曲菜单提供收藏、加入歌单和不感兴趣。

点击搜索框立即进入搜索状态，可先选择网易云、QQ 或两者。没输入关键词时显示最近搜索；提交后显示搜索结果。
清空关键词保留搜索状态和音源选择，取消返回推荐。系统键盘收起只改变输入焦点，不用于判断是否退出搜索。

## 基础推荐

无需账号、API Key 或服务器数据库。收藏权重最高，结合歌单里的歌手、实际收听和手动提前跳过记录，
用现有音乐搜索发现同歌手歌曲；不足时补充内置公开歌单（网易云 ID `3778678`）。
过滤已喜欢、最近有效收听和不感兴趣的歌曲，优先让不同歌手都有机会出现。同一歌曲在两音源的重复结果只保留一份。
离线或开启只播缓存时，只展示本机已缓存且未标记不感兴趣的歌曲，这时允许已有收藏。

有效播放按实际音频进度累计：达到 30 秒，或短歌的一半时长（至少 5 秒），记一次有效播放。
暂停、缓冲与跳转进度不计入收听时长；实际收听 5 至 30 秒内手动换歌记一次弱负反馈。
加载失败、重试、自然结束和自动切歌不作为不喜欢的信号。

基础候选池缓存 6 小时。音乐接口不可用时保留旧池，必要时使用本地曲库；失败后不会在每次渲染时连续重试。

## 配置 AI

在设置的「AI 推荐」区域填写：

- API 地址：OpenAI 兼容 Chat Completions 服务的基础地址，例如 `https://api.example.com/v1`；也可填写完整的 `/chat/completions` 地址。
- API Key：自己在该服务取得的 Key，界面默认隐藏。
- 模型名称：服务商提供的模型 ID。

第一版使用 HTTPS 默认 443 端口，不支持 HTTP、本地/内网转发地址、带账号或查询参数的 URL。
测试连接会发送一次很短的模型请求，不上传偏好。保存并启用后使用所保存的配置；编辑未保存的字段不会改变运行中的配置。

模型一次返回最多 50 个「歌名 + 歌手」候选，不生成长篇推荐理由。请求最多使用 2400 个输出 token，
输入只含最多 8 位偏好歌手、24 首收藏、24 首近期有效收听与 12 首不感兴趣的歌，不发送整份曲库、歌词或诊断记录。
模型效果取决于服务本身和偏好数据，不保证比基础推荐更准确。

候选逐首通过音乐 API 搜索核验，最多同时核验两首（每首可查两个音源）。歌名或歌手不一致、翻唱/现场版本不对应的结果被舍弃。
搜索到曲目不代表一定可播放，实际播放仍沿用原有链接解析、重试和自动跳过机制。首次核验一批，剩余候选在恢复或换一批时继续核验。
首页每次展示 12 首；换一批使用本地候选和音乐查询，**不请求大模型**。只在真正播放时加载播放链接等详情，不为推荐列表下载音频。

AI 缓存最多使用 7 天。自动补充仅在启用该选项、推荐不足时进行，每 24 小时最多自动请求一次，失败也计入间隔。
手动重新生成不受此自动间隔限制，会调用模型，可能产生费用。连接测试也可能计费。
Key 错误、限流、超时、格式错误或找不到真实歌曲时继续使用有效旧池或基础推荐，不自动反复重试模型。

更换 API 地址、Key 或模型会使旧配置的 AI 池失效。关闭 AI 立即使用基础推荐；清除配置会删除本机保存的 Key，
并丢弃迟到的请求结果。已经发出的模型请求仍可能由服务商完成和计费。

## 数据与请求路径

- `listening-ai-config-v1`：设备上的 `localStorage`，保存所配地址、模型、Key 与开关；密码输入框只负责界面隐藏。
- `listening-recommendations-v1`：推荐元数据、剩余候选、有效收听及不感兴趣记录；不包含 Key、音频链接或歌词。
- 原歌单存档、`LSNPL1:` / `LSNPL2:` 导出格式和诊断格式不变。清除 AI 配置不删除歌单或本地偏好。
- 网页通过同源 `POST /recommendations/ai` 转发。Key 仅放在 Authorization 请求头，临时经过 Listening 服务器后交给所配模型服务，不写磁盘、缓存或日志。
- APK 使用已有 `CapacitorHttp` 直接向所配服务发 HTTPS POST，不经过 Listening 的 AI 转发，不启用全局 fetch 接管。

网页转发不是通用 HTTP 代理：只构造固定模型请求，限制输入、输出和总时长，不跟随重定向。
DNS 返回地址均须为公开地址，连接固定到校验后的 IP，保持目标域名的 TLS 校验；运行环境配置了代理时沿用该代理。
上游错误只返回预定义错误码，避免服务商响应将 Key 带进错误信息。

## 验证

`node tests/run.mjs recommendations recommendations-ui` 覆盖候选匹配、缓存、自动间隔、取消竞态、收听信号、
网页转发边界、真实页面交互和模拟 APK HTTP 路径。测试使用本地/模拟服务，不消耗真实模型额度。
`layout`、`i18n`、`icons` 继续覆盖中英文及多尺寸。无网络的旧测试预置推荐缓存，避免首页冷启动请求干扰各自的测试目标。
Android 软键盘、系统返回与真实模型服务仍需 APK 和用户自己的 Key 实测。
